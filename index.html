Lila takes its UX and workflow from Maya, then rebuilds everything else for game developers: a modern stack, real multithreading, and high-end tools across the board.

Lila fits a solo indie as well as a AAA studio's full production pipeline, and every part of it is built to be extended. Its architecture is designed to last, not patched together.

One tool, from first polygon to Unreal

  1. Model
  2. Unwrap
  3. Bake
  4. Texture
  5. Rig
  6. Animate
  7. Unreal

No exporting FBXs or textures between apps, and no separate UV tool, baker, painter or material generator. Everything happens in Lila and lands in Unreal on save.

Pipeline

  • Live Unreal sync

    Send a mesh to Unreal once. From then on every save reimports it, with no export and import dance.

  • VFX meshes, straight to Unreal

    Build animated meshes with geometry nodes, then send them as a Niagara mesh flipbook or an Alembic cache.

  • Collision meshes

    Generate correctly oriented bounding meshes. Use them as UCX_ starting points or as-is.

  • Opens Maya scenes

    Open .mb and .ma files and convert them to Lila scenes.

Modeling, sculpting and UVs

  • Symmetry that stays exact

    Across modeling, UVs, weights and joints. Precision never drifts one side away from the other.

  • Auto-bevel

    Lila can pick the edges you'd bevel, so you don't have to select them by hand.

  • Sculpting

    Sculpting tools built into modeling, for shaping and refining meshes without leaving Lila.

  • Edge loop to faces

    Turn an edge loop into the faces it encloses in one step.

  • Geometry nodes

    Procedural modeling in a node graph with keyable inputs, for anything from props to VFX meshes.

  • UVs that unwrap well

    Auto-unwrap that gives good results, live physics-based relax, flatten and settle, and paintable modifiers such as relax, flatten, smooth boundary and pin.

Baking and texturing

  • GPU texture baking

    Bake the mesh maps you need for texturing on the GPU, with channel packing and UDIMs.

  • Material nodes

    Build procedural materials in a node graph, with every baked mesh map available as an input.

  • 3D painting

    Paint layers directly on the mesh with materials, not just colours: paint rust and the rust material fills every channel.

Rigging and animation

  • Animation, taken further

    Inspired by Akeytsu, with Jolt physics for procedural motion and physics-based posing, and space switching built in.

  • Rigging your way

    Automated rigs when you want speed, film-grade control when you don't.

  • Euler or quaternion

    Switch any joint between the two. Gimbal lock only when you choose it.

Working in Lila

  • Light and quick

    Lila feels light next to other DCCs: fast to work in, easy to learn and out of your way.

  • Modern viewport

    A Vulkan renderer built for realtime: image-based lighting, clean anti-aliasing, a neutral backdrop that doesn't skew your colours.

  • Find any tool

    Press Ctrl+T and type. No hunting through menus for the editor you can't remember the location of.

  • Floating shelf

    Call your shelf up at the cursor, so your tools are right where you're working instead of across the screen.

  • Shareable parameter windows

    Build a custom parameter window, then copy it as text or export it for someone else to use.

  • Agentic workflows

    Built-in support for AI agents, which drive the same commands you do. Describe an effect and an agent builds the geometry node graph for it.

  • Themes

    Change the look to suit you.

Scripting and extensions

  • Python without the ceremony

    No imports or namespaces, just the command.

  • A real script editor

    Completion, auto-format, inline docs and relative line numbers. You won't miss an external IDE.

  • Batch over whole directories

    Need to change, or gather data from, 100 scenes? Script it once, then run it over a directory with powerful file filtering.

  • Declarative UI

    Build tool windows from Python without wrestling a layout system.

  • C++ extensions

    Designed for extensions from the ground up, with a published SDK.

# Changelog

What changed in each Lila release, newest first. The welcome screen shows the latest entry under **What's New**.

## 0.1.0 - 2026-11-15

- Texture painting in the Texture Set dock, with 165 brush presets, 343 alphas and polygon and triangle fills
- 52 smart materials and 79 smart masks, all tagged, dragged from the smart shelf onto meshes or into the layer stack
- Import Substance Painter smart materials, smart masks and brush presets: **Texture > Import from Painter**
- Procedural layers expose tiling, rotation, offset and their graphs' settings
- 13 new layer blend modes, including colour dodge, linear burn, pin light and divide
- Texture previews evaluate on the GPU, and shader builds no longer stall the viewport
- Baker inputs prepare in seconds and abort per mesh
- Quad Remesh: paint density on faces, density volumes, and hard edges off by default
- Tailor gloves, mittens, shoes and boots, fitted to the body's hands and feet
- Option boxes open at the viewport's left edge, and long choice lists get a searchable grouped editor
- Node editor: Alt+click a socket to disconnect it
